# TCP 自定义协议演示 - 流程图

## 会话生命周期

```
┌──────────┐                 ┌──────────┐              ┌──────────┐
│  Vue 前端 │                 │ Go HTTP   │              │ TCP Server│
│          │                 │ (Handler) │              │ (:9090)  │
└────┬─────┘                 └────┬─────┘              └────┬─────┘
     │                           │                          │
     │ 1. POST /tcp/sessions     │                          │
     │ ────────────────────────> │                          │
     │                           │ net.Dial("tcp", :9090)  │
     │                           │ ─────────────────────>  │
     │                           │ ←─── 连接建立 ────────  │
     │                           │                          │
     │ ←─── session_id ──────── │                          │
     │                           │ SessionPool.Add(sess)   │
     │                           │                          │
     │ 2. GET /tcp/sessions/:id/stream (SSE)                │
     │ ────────────────────────> │                          │
     │ ←─── connected 事件 ──── │                          │
     │                           │                          │
     │ 3. POST /tcp/sessions/:id/send {"command":"PING"}    │
     │ ────────────────────────> │                          │
     │                           │ conn.Write("PING\n")    │
     │                           │ ───────────────────────> │
     │                           │                          │ 协议解析
     │                           │ ←─── "PONG\n" ───────── │
     │                           │                          │
     │ ←─── {"response":"PONG"} ─│                          │
     │                           │                          │
     │ 4. DELETE /tcp/sessions/:id                          │
     │ ────────────────────────> │                          │
     │                           │ conn.Write("QUIT\n")    │
     │                           │ ───────────────────────> │
     │                           │ conn.Close()            │
     │                           │ SessionPool.Remove(id)  │
     │ ←─── {"closed":true} ──── │                          │
     │                           │                          │
```

┌─────────────────────────────────────────────────────────────┐

## 设计亮点

1. **TCP Server 完全独立**：与 HTTP Server 同一进程、不同端口，通过 SessionPool 桥接
2. **读写超时保护**：每个连接配置 ReadTimeout 和 WriteTimeout，防止慢客户端挂死
3. **并发安全**：SessionPool 使用 sync.RWMutex，SendCommand 使用 conn 自带锁
4. **自动清理**：SessionPool.Cleanup() 定期清理死连接，防止泄漏
5. **事件通道非阻塞**：emitEvent 使用 select+default，慢 SSE 客户端不会影响 TCP 连接
