# WebSocket 实时通讯 - 连接流程

## 完整连接流程

```
┌──────────┐                                          ┌──────────┐
│  Client  │                                          │  Server  │
└────┬─────┘                                          └────┬─────┘
     │                                                     │
     │  1. 用户登录获取 JWT Token                           │
     │  POST /api/v1/auth/login                           │
     │ ─────────────────────────────────────────────────> │
     │ <───────────────────────────────────────────────── │
     │  { "access_token": "eyJhbG...", "expires_in": 7200 }│
     │                                                     │
     │  2. 建立 WebSocket 连接                              │
     │  GET /api/v1/chat/ws?token=eyJhbG...               │
     │  Upgrade: websocket                                │
     │  Connection: Upgrade                               │
     │ ─────────────────────────────────────────────────> │
     │ <───────────────────────────────────────────────── │
     │  101 Switching Protocols                           │
     │                                                     │
     │  3. 加载聊天室列表（REST API）                        │
     │  GET /api/v1/chat/rooms                            │
     │ ─────────────────────────────────────────────────> │
     │ <───────────────────────────────────────────────── │
     │  [{ "id": 1, "name": "公共大厅", ... }]              │
     │                                                     │
     │  4. 加入房间                                         │
     │  { "type": "join_room", "payload": {"room_id": 1} } │
     │ ─────────────────────────────────────────────────> │
     │                                                     │
     │  5. 服务端处理加入                                    │
     │                                                     │
     │ <─────────────── room_history ──────────────────── │
     │  { "type": "room_history", "payload":               │
     │    { "room_id": 1, "messages": [...] } }            │
     │                                                     │
     │ <─────────────── user_joined ───────────────────── │
     │  { "type": "user_joined", "payload":                │
     │    { "room_id": 1, "user_id": 1, "username": "admin"} }│
     │                                                     │
     │ <─────────────── online_users ──────────────────── │
     │  { "type": "online_users", "payload":               │
     │    { "room_id": 1, "users": [...], "count": 1 } }   │
     │                                                     │
     │  6. 发送消息                                         │
     │  { "type": "send_message", "payload":               │
     │    { "room_id": 1, "content": "你好！", "msg_type": 1 }}│
     │ ─────────────────────────────────────────────────> │
     │                                                     │
     │  7. 服务端持久化消息并广播                             │
     │                                                     │
     │ <─────────────── new_message ───────────────────── │
     │  { "type": "new_message", "payload":                │
     │    { "id": 1, "room_id": 1, "user_id": 1,          │
     │      "username": "admin", "content": "你好！",        │
     │      "msg_type": 1, "created_at": "..." } }         │
     │                                                     │
     │  8. 输入指示器（防抖 2 秒）                            │
     │  { "type": "typing", "payload": {"room_id": 1} }   │
     │ ─────────────────────────────────────────────────> │
     │                                                     │
     │ <─────────────── user_typing ───────────────────── │
     │  { "type": "user_typing", "payload":                │
     │    { "room_id": 1, "user_id": 1, "username": "admin"}}│
     │                                                     │
     │  9. 心跳保活（每 30 秒）                              │
     │  { "type": "ping", "payload": {} }                 │
     │ ─────────────────────────────────────────────────> │
     │ <─────────────── pong ──────────────────────────── │
     │  { "type": "pong" }                                 │
     │                                                     │
     │  10. 离开房间                                        │
     │  { "type": "leave_room", "payload": {"room_id": 1} }│
     │ ─────────────────────────────────────────────────> │
     │                                                     │
     │ <─────────────── user_left ─────────────────────── │
     │  { "type": "user_left", "payload":                  │
     │    { "room_id": 1, "user_id": 1, "username": "admin"}}│
     │                                                     │
     │  11. 断开连接                                        │
     │  WebSocket Close (1000)                             │
     │ ─────────────────────────────────────────────────> │
     │                                                     │
```

## 客户端重连流程

```
┌──────────┐                ┌──────────┐
│  Client  │                │  Server  │
└────┬─────┘                └────┬─────┘
     │                           │
     │  连接断开（网络异常）       │
     │  <--- Close (非 1000) --- │
     │                           │
     │  等待 1s + 随机抖动        │
     │  ...                      │
     │                           │
     │  尝试重连 #1               │
     │  GET /api/v1/chat/ws ...  │
     │ ───────────────────────> │
     │  失败                     │
     │ <─────────────────────── │
     │                           │
     │  等待 2s + 随机抖动        │
     │  ...                      │
     │                           │
     │  尝试重连 #2               │
     │  GET /api/v1/chat/ws ...  │
     │ ───────────────────────> │
     │  成功 (101)               │
     │ <─────────────────────── │
     │                           │
     │  重新加入之前的房间          │
     │  { "type": "join_room"... }│
     │ ───────────────────────> │
     │                           │
```

**重连策略：** 指数退避 + 随机抖动
- 基础延迟: 1 秒
- 最大延迟: 30 秒
- 最大重试: 10 次
- 公式: `min(1000 * 2^retryCount, 30000) + random(0, 1000)` ms
